# Fine-tuned Cellpose model

## Files

| File | Size | Description |
| --- | --- | --- |
| `cellpose_1777550975.949237` | 26 MB | Self-trained `cyto3` weights (cyto3 + adaptive normalize outputs filtered to 586 pseudo-GT pairs). |
| `cellpose_1777590610.8133328` | 26 MB | **Quimp-trained** `cyto3` weights (14 biologist-validated cells, 502 image-mask pairs un-shifted to raw frame). Used for the Day 3 cross-validation. |

## Provenance

- **Base model**: `cyto3` (Cellpose 3.x).
- **Training data**: 586 pseudo-ground-truth pairs, generated by running v3 (cyto3 + adaptive normalize) on the original 30 cells in `Categorised_Data/`, then filtering: mask area >= 30% of per-cell median, IoU >= 0.5 with the previous frame, frame stride 10. Files `ko1/4` and `ko1/8` excluded (95% / 50% empty in v3, would have polluted the training data).
- **Hyperparameters**: 100 epochs, learning rate 0.05, weight decay 0.0001, `--min_train_masks 1` (each frame has a single instance), GPU. See `pipeline/run_finetune.sbatch`.
- **Wall time**: ~12 minutes on RTX A5000.

## Performance

| Dataset | Empty-mask rate (v3 cyto3) | Empty-mask rate (this model) |
| --- | --- | --- |
| Original 30 cells (training source, batch 1) | 2.83% | 0.13% |
| Fresh 30 cells (held-out, batch 2) | not measured | 1.28% |

22-fold reduction on the cells used to filter training data, generalises with empty rate still under 2% on a fresh batch the model never saw. See the main README for the full comparison and the briefing page for the generalisation discussion.

## How to use

```python
from cellpose import models
m = models.CellposeModel(pretrained_model='models/cellpose_1777550975.949237', gpu=True)
masks, flows, styles = m.eval(image, diameter=None, channels=[0, 0])
```

The pipeline scripts `process_with_finetuned.py` and `process_2nd_with_finetuned.py` expect this file inside `Categorised_Data_centered/training_data/models/` on the Warwick CS server (so they can pick up the most recent file in that directory). To run them with this repository's copy, change the `TRAIN_DIR` constant near the top of those scripts, or symlink the file into the expected path:

```bash
mkdir -p ~/Desktop/Categorised_Data_centered/training_data/models
ln -s "$(pwd)/models/cellpose_1777550975.949237" \
      ~/Desktop/Categorised_Data_centered/training_data/models/
```

## Caveats

- Trained on filtered self-segmentations (no hand-drawn ground truth). The model has learned the *consensus shape* that v3 cyto3 produces on this dataset family. It is therefore biased toward the kinds of cells v3 already segments well, which is why `ko1/7` (28% empty in batch 2) is still hard.
- Single-instance per frame. Will not produce multiple cell IDs in a frame; designed for the one-cell-per-recording layout of this dataset.
- Architecture and tile size are inherited from `cyto3`. No structural changes.
